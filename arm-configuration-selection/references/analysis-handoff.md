# 后续分析衔接

本技能可独立完成构型初选，不依赖其他技能、Python、Node或原始挂载盘。以下是同仓库可选工具；使用前确认可用，并读取当前SKILL.md及输入契约。

| 问题 | 可选技能 | 前提与边界 |
| --- | --- | --- |
| 位置、朝向及采样工作空间 | arm-workspace-parametric | 具体串联轴系、变换、杆长、限位、工具、安装与目标坐标；不检查碰撞或带载；数值未解不等于不可达 |
| 平举、静态保持、安装与重力 | arm-statics-parametric | 几何、质量、质心、工具/载荷归属、姿态及重力；不代替动态和热验收 |
| 轨迹、速度、加速度、奇异性和逆动力学 | arm-kinematics-dynamics | 契约中的几何、轨迹、限位和必要物理参数；只覆盖声明工况 |
| 模型生成 | arm-sim-model-generator | 固定基座单条revolute/prismatic/fixed串联刚体链；显式映射输入，不直接传选择记录或其他normalized输出 |
| 接触与任务仿真 | arm-mujoco-task-sim | 具备模型、驱动、场景和任务条件；核对当前支持范围，任务通过不证明全空间能力 |

## 拓扑先于格式

2-SPS-U、2-SPU+1U、Stewart、差分/连杆闭环、绳驱柔性或连续体，先检查下游能否表达真实约束、传动和弹性。

使用等效旋转链时注明假设、忽略内容和可得结论。本项目混合臂URDF的7个旋转广义坐标不表示已经验证丝杠行程、闭环支链、力映射和干涉。两个单轴极值不组成可随意组合的矩形域。工具不支持时交付所需模型数据和验证方案，不强行改成默认串联例子。

## 分开保存选择记录与具体模型

本技能先交付候选、依据、取舍和缺项。用户要求继续且参数足够时，才建立下游请求：命名与连接、局部轴系、相对变换、工具、有限限位、安装及重力；按目标追加质量、质心、惯量、驱动、负载和轨迹。每项标注来自用户、原模型、计算或经确认的概念估算。

缺项不从3kg/600mm参考臂、FR3或其他示例自动补入。多个候选保留各自输入与假设；没有同任务、同口径的计算，不用各产品额定值拼成统一排名。

## 机构族的工具适配

F01/F02/F03/F04等若能建立符合契约的固定基座单条R/P串联刚体模型，可在显式映射后使用相应串联分析工具。F05/F08/F09/F10若包含闭环/耦合，先核对实际实现，不能仅按轴数决定支持。F11需正张力和锚点模型，F12需受载形态/连续体模型，F13需入口约束验证。底盘/双臂协调不在单臂固定基座结果内。本知识库支持提出这些候选，不表示工程工具获得了新拓扑能力。
