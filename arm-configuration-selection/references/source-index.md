## 推理与证据的区别

G01—G08是本库基于上述原理及通用工程知识整理的**设计推理**，不是新实验结果，也不是原作者给出的构型排名。引用时同时写G编号、依据E编号、所用任务假设和待验证条件。厂商页面仅支持所述实例，不能给整类方案背书。

| 推理编号 | 内容 | 主要依据 |
| --- | --- | --- |
| G01 | 任务运动要求与轴数初筛 | E01、E02、E03 |
| G02 | 基础构型与任务域对应 | E09、E10、E11、E12、E19、E21 |
| G03 | 冗余、几何、工具包络与路径 | E02、E03、E04 |
| G04 | 载荷、传动、感知与接触取舍 | E05、E06、E07、E16 |
| G05 | 固定/导轨/移动/双臂部署核查 | E08、E09及哈工大部署资料 |
| G06 | 绳索、连续体、RCM的附加约束 | E14、E15、E17、E18 |
| G07 | 同任务验证顺序与公平比较口径 | E02—E08及原技能证据边界 |
| G08 | 场景候选与提问分支 | G01—G07，在场景表逐行注明 |

本知识库不声称穷尽机器人机构。重载液压、磁驱微机器人、空间浮动基座、并联机床等尚缺专题资料；遇到这些任务先标注覆盖不足，再约定所需资料。


## 维护方式

新证据放入相应构型/场景/设计专题，更新本登记的来源位置与支持范围；相同内容合并，冲突并列。不要按来源机构增设知识模式，也不使用新宣传规格覆盖旧版本案例。包内资料哈希记录随每次发布单独保存，旧版本快照不作为当前文件校验值。
