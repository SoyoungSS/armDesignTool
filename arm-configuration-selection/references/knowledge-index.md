# 机械臂构型选择知识库

围绕“任务→运动需求→机构与轴系→驱动/感知/部署→约束比较→验证计划”组织统一知识库。资料来自多种报告、研究、教材与实现实例，选择流程不按来源分流。来源只在追溯和解释结论范围时使用。

## 统一条目的阅读方法

构型条目比较：运动与自由度、优势、代价、已有实现、任务条件、部署与待验证项。F01—F13是机构族检索编号；SRS/偏置、传动/感知、固定/移动是可组合的不同维度。不能只凭“7轴”“协作”“绳驱”等一个标签决定完整方案。

场景表给条件候选；具体案例保留自己的参数范围。来源事实与工程推理分开，缺数据写未知。未收录不代表路线不存在，原理支持也不代表具体新设计验收通过。
