# 部署方式与整机集成

部署方式决定安装与覆盖条件，不直接决定机械臂属于6轴、7轴、串联或并联。

| 部署方式 | 材料对应的场景 | 对机械臂方案的主要影响 | 已有参照与证据边界 |
| --- | --- | --- | --- |
| 固定工位 | 精密装配、接触加工、固定位置操作 | 对照工位目标位姿、工具、安装位置及工作空间；移动平台的质量约束不直接照搬 | I的固定协作臂分析；C中的工业操作案例 |
| 轮式移动平台 | 仓储、实验室、家庭、柔性制造 | 质量、供电、控制器、线缆与底盘配套；可能利用躯干升降扩大覆盖 | NERO/PiPER配套、R1 Pro、A2-W、Reflex等；整机覆盖范围不等于臂长 |
| 双足或人形躯干 | 仿人操作、步行与操作协同 | 上肢质量、惯量、质心与全身控制耦合；明确手臂主要承担操作还是运动辅助 | C 3.1；MIT、UCLA四轴研究与7轴仿人臂分别对应不同目标 |
| 固定车位充电 | 家用窄车位 | 收纳包络、停车误差、接口姿态、工具与线缆 | 小米、开拓者Robot；不把推测轴数作为设计定值 |
| 移动或导轨覆盖多个车位 | 公共场站、车队 | 平台移动覆盖与局部对接能力分开设计 | Rocsys M1及报告中的移动抓枪方案；一机多车位不等于同时作业 |
| 四足搭载及臂足复用 | 危险环境移动操作、故障回收构想 | 分清一般搭载机械臂与特殊臂足替换结构 | I的移动操作展望与J09专利，成熟度不同 |

来源事实、参考设计参数与设计推理分别解释，编号统一查[来源登记](source-index.md)。参考设计的限位、质量或性能不是同类机构的通用参数。与任务的匹配和验证顺序见[设计取舍](design-tradeoffs.md)与[验证清单](verification-checklist.md)。
