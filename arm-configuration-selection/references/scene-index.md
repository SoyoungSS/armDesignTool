# 按任务场景选择构型

本表把场景要求映射到可比较的构型与配套条件，属于设计推理，不是来源作者对用户任务的实测推荐。先读[任务与自由度](task-dof-selection.md)，再根据条件选择下表；F编号见[构型总表](arm-layouts.md)，E/G来源见[登记](source-index.md)。

| 场景与明确条件 | 优先纳入比较的方向 | 何时改变候选/条件 | 部署核查与首个验证 | 推理依据 |
| --- | --- | --- | --- | --- |
| 矩形台面检测/点胶，工具姿态固定 | F01 XYZ/龙门；若仅平面可降为XY | 工具需倾斜、侧面进入或绕障时增加姿态轴/比较F06 | 横梁、导轨、台面和拖链；同任务行程与带载误差 | G01/G02/G07；E02/E09 |
| 竖直工具桌面取放，需绕竖直轴转 | F04 SCARA、XYZ＋R；节拍要求高再比较F08适用版本 | 取放外还要翻面/斜插，常规SCARA需重查 | 平面域、Z行程、倾覆/转动惯量、夹具 | G01/G02；E10/E11 |
| 传送带轻件高频分拣 | F08 Delta、F04或适配布局 | 物体倾斜重定向、追踪范围、实际负载/工具改变时重比 | 顶部空间、相机时延、同步跟踪和完整循环；不抄宣传节拍 | G02/G07；E10/E11 |
| 保持箱体/袋体方向的码垛 | F05专用4轴、F01；F06作姿态扩展备选 | 需翻转、多方向抓取、异形堆垛时增加姿态需求 | 托盘高度、进出料、抓手COM/惯量、基础 | G01/G02；E09/E21 |
| 多方向加工/扫描/喷涂 | F06；有内部绕障目标时比较F07 | 旋转对称工具可释放自转，但电缆/工艺可能不允许 | 每阶段工具姿态、臂体和线缆路径；不是只看TCP球半径 | G01/G03；E02/E03 |
| 胸前双臂/遥操作/窄空间调肘 | F07的SRS/偏置，和适配任务的F06比较 | 未要求保持位姿调肘时不先锁定7轴；类人外形也是独立约束 | 胸前/头侧/背部目标、双臂干涉、工具/操作员包络 | G03/G05；E03、A/B/C |
| 插装、拧紧、擦拭、打磨等接触 | 先按任务位姿选F04/F06/F07等，再比传感/驱动 | 法向力、接触刚度、工具扭矩与接口可能改变设计；不必然选并联腕 | 姿态域、结构受力、力控方向与实际接口 | G04；E05/E07/E16 |
| 小范围六维精密对准 | F09平台；F06/F07或串联精密轴作对照 | 长距离搬运不是局部平台天然优势；可分粗定位＋精调 | 联合位姿域、负载位置、支链和测量方法 | G02/G07；E01/E12 |
| 围绕中心工件，径向伸缩/升降 | F02、F03、F01或F06按姿态需求对照 | 非环形任务域、中心穿越或多方向摆姿会改变收益 | 基础/伸缩受力、中心退化、扫掠区域 | G02/G03；E19 |
| 大空间/大尺寸构件定位 | F01、臂＋导轨、F11绳索平台 | 锚点不允许、存在人员/设备穿绳路、张力不解时CDPR保留条件/排除具体布局 | 基础/锚固、外轴精度或正张力可行域及绳路 | G05/G06；E09/E17/E18 |
| 狭孔后弯曲通道检查 | F12连续体；能沿直通道完成时比较刚性伸入工具 | 需要显著接触力/精度时先核实受载形态；不能泛称所有柔性臂无能力 | 插入退出、形态观测、摩擦与末端受力；研究路线条件候选 | G06；E14 |
| 必须绕固定入口点操作 | F13 RCM专用结构；或满足约束的其他机构方案 | 是否机械约束/控制约束、是否有插入和远端腕需求需明确 | 入口配准误差、整个动作路径和工具形态；不是临床适用判断 | G06；E15 |
| 移动上门操作，多高度工作面 | 底盘＋F06/F07，或升降＋较少轴任务臂 | 可驻车与必须边走边操作是不同问题；不能自动靠底盘补腕维数 | 底盘定位/稳定性、组合雅可比、接触反力、收纳 | G05；E08 |
| 动态交互/投掷等，重视远端惯量 | 近端远传、低减速比及合适关节布局；按任务姿态选整臂 | 高速目标不抵消刚度、张紧、热和精度需求；不能移植论文倍率 | 运动质量、折算惯量、传动弹性与全周期动态负载 | C 3.2.2/3.2.3；J01/J02；G04 |
| 低成本科研，允许明确的精度取舍 | 准直驱、简化感知与适当轴数；和现成模组路线对照 | 低采购成本不等于低维护/集成成本；需明确允许误差 | 电流力矩估计、摩擦、持续热、制造与维护能力 | C 3.2.2；J01；G04 |
| 上肢主要摆臂、平衡或支撑 | 肩3肘1等简化4自由度功能子方案 | 若还需通用操作或主动腕，必须增加相应能力，不能沿用简化假设 | 支撑载荷、上肢质量、整机控制和是否需要腕部 | J05/J06；G01/G05 |
| 自动充电，重视收纳及停车偏差 | 紧凑刚性臂、局部并联对接、柔性/连续体及移动覆盖组合 | 收纳、形态适应与精密插拔是不同要求；路线不能仅凭柔顺性决定 | 枪头/线缆、插拔方向/力、停车误差、局部姿态域与长期精度 | C 第4章；J07/J08；G04/G06 |

用户只说“服务/家用/工业”不足以选构型。先收集能改变候选的动作、姿态、载荷和部署条件，再列有依据的候选；不要套用场景表作为硬性规则。
