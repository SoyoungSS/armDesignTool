# 从任务构建场景与策略

默认前期概念试算遵循[常规假设](concept-trial.md)：无需先向用户索要完整工具/环境/控制说明，直接选择最简单可行路线并记录假设。下文的逐项确认和备选审批适用于严格模式；用户已委托的概念简化不重复确认。工具细节不足时可用明确标记的 load_proxy 先导出载荷谱，不宣称真实任务已验收。

## 路线选择

先从任务原文提取工件、工具、操作面、位姿来源、运动目标、力/速度约束和成功证据。已有指定策略或约束优先。按下面的任务倾向生成方案草稿，参数值从用户答复、上游模型或经批准的估算取得。

| 工况 | 首选路线及适用条件 | 何时提出第二条路线 | 判定动作成功的证据 |
|---|---|---|---|
| 已知位置的抓放 | 用许可的工件位姿生成预抓取位，求带限位 IK；接近、对齐、闭合、试抬、搬运、落位、松开、撤回。按夹具实际能力建立抓持。 | 工件位置变化且任务允许相机时，提出检测定位后规划；接近误差需实时修正时提出视觉伺服，说明标定、帧率和遮挡代价。 | 指垫实际接触、抬起后相对滑移、支撑转换、释放后稳定与放置误差。 |
| 擦拭或推压 | 已知操作面时先规划自由空间接近，再沿面切向运动。法向用有界的力反馈或阻抗控制，退出后退出接触控制。 | 仅需几何轨迹且接触柔顺已知时，可比较位置跟踪路线。力目标或力传感器未确认时，先问目标与可观测量。 | 有效接触区域的覆盖、法向力时序、越界与分离；推物另查实际位移及倾覆。 |
| 插装与狭窄通道 | 按公差约束接近与对准，限制速度、力和侧向偏移；明确卡滞后的退回条件。 | 位姿不确定且允许探测时，比较带力觉的小范围搜索，列明传感器和搜索范围。 | 实际插入深度、侧向误差、峰值力、卡滞或成功退出。 |

**给执行 agent 的提示词**

> 根据已确认的状态来源、工具和成功判据，写出最简单可行的阶段表。每行写进入条件、动作、允许/必须的接触、可观测的完成条件和失败后的动作。只在两条路线会改变传感器、物理假设、算力需求或可验收结果时，给用户并列方案。每条写适用条件、额外资产或依赖、主要失败方式和验证证据。推荐一条并解释它为何符合本次目标。用户已经选定路线时进入实现。

例如，位置随机的抓放任务可问：“你希望验证夹持和搬运动作，还是要求机器人自己找出工件？前者可在获准使用真实位姿后直接规划；后者需要相机标定和定位误差验收。两条路线都用实际指垫接触和释放后稳定性验收。”

用[路线模板](../assets/strategy.template.json)填写 `plan/strategy.json`。写明选定路线、选择依据、观测来源及每个阶段的进入条件、指令、退出证据和失败动作。存在实质选择时，在 `alternatives_considered` 记录各路线的前提、取舍和用户答复。场景预检查验模板中的必填字段，并比对阶段标识与碰撞合同。已采用其他策略文件格式的历史项目可继续使用。若方案不可行，先给出具体原因（不可达、力限不足、传感器缺失或通道净空不足），再提交改变任务假设最少的备选路线。

## 场景分解

逐项写入 `assets/manifest.json`：id、用途、来源（生成/用户提供/外部）、路径/hash、单位、视觉与碰撞表示、尺寸、可动性、质量/COM/惯量及来源、摩擦/接触参数、安装坐标、批准记录、资源许可证（外部资产）。资产数量由任务决定。

用基础几何即可满足物理目的时优先 MJCF primitives；复杂外观可生成 mesh，但碰撞用经验证的简化体/凸分解。图像纹理不是接触几何，视觉生成模型也不自动带有正确物理属性。动态物体使用惯量和自由关节，固定环境不可误赋移动自由度。薄板、抓取物和细小接触检查尺度、时间步和穿透。

抓放通常需要夹具、可抓物、支撑面、目标容器/区域，可能需要相机和光照；擦拭需要表面、工具、字迹状态；插装需要孔/销公差和接触柔顺；推压需要对象运动约束、接触目标及力限制。它们是提问线索，不是固定资产模板或用户未提供参数的默认值。

## 策略优先级

1. 执行用户指定方法，若不可用，解释具体缺项和候选替代，得到确认后再改。
2. 无指定方法：提出基于规划的方案。拆任务状态机，构造抓取/接触目标，求 IK，做碰撞检查和时间参数化，使用有界位置/阻抗/力反馈。概念模式记录策略与真值观测假设后直接执行；严格模式先确认。
3. 说明初始可达性、奇异位形、冗余分配、速度/加速度/力矩限幅、失联/未识别/滑落等失败转移。规划目标与实际到达状态分别记录。

## 感知与控制不能混淆

| 指定方法 | 实现与证据 |
|---|---|
| 仿真位姿抓取 | 从 body/site 读取真值，明确坐标变换、抓取偏置与抓取候选；报告写“真值位姿” |
| 检测后抓取 | 相机图像 → 检测/分割 → 深度或几何定位 → 外参转换 → 规划；保存图像、检测输出、标定、置信度、时间戳和失败重试 |
| 视觉伺服 | 按相机帧率连续观测图像特征或视觉估计位姿，按图像/位姿误差闭环控制；记录延迟、采样保持、误差和饱和 |

视觉算法可用 MuJoCo 真值作**独立评价**，不能偷偷送进控制器替代识别。仿真分割/深度真值属于特殊传感器假设，必须向用户说明并确认；离屏摄像机需要渲染依赖/设备，WebViewer 的浏览器画面不会自动成为 Python 相机观测。

## 接触与载荷

物理抓取需要夹爪驱动、足够夹持力和接触摩擦，验证物体相对末端的滑移、保持与释放。吸附/焊接约束仅作为明确批准的简化；记录开关时刻和反力，不称为真实夹持验证。

不要靠逐帧写关节 qpos 或直接搬动物体实现“成功”。除初始/轮间已批准的复位外，运动经驱动和动力学产生。不得为了通过而移除应有碰撞、改变用户指定质量或加虚假惯量。

每个阶段定义进入条件、动作、退出/成功条件、超时和失败策略。按确认轮数统计成功/失败/重试/未开始的轮次。复位作为事件记录，其非物理跳变不能计入速度/加速度/载荷统计。
