# 接触回归与跨 agent 对照

在任务仿真环境执行 `python scripts/collision_regression.py --output <新的测试目录>`。命令生成独立场景、合同和控制器，走正式运行器的无窗口入口。每个项目的 `runs/<id>/reports/result.json`、`preflight.json` 和 `data/contacts.csv` 保存原始证据。合同内的测试批准仅用于合成夹具。

同一台 Windows x64、Python 3.11、MuJoCo 4.0.1，固定种子 1 和步长 0.002 s，使用相同夹具对比了提交 `a66ecfd` 的运行器与新增规则的运行器。

| 场景 | 原运行器 | 加入独立接触判定后的预期、实测 |
|---|---|---|
| 正常夹取、搬运、放置 | 通过 | 通过。双侧夹垫在搬运时有正法向力，释放后工件由桌面支撑。 |
| 搬运时前臂短暂撞桌，随后收回，工件到达目标 | 通过 | `carry` 检出 `forearm/table` 禁止接触。 |
| 下降时提前松爪，工件仍掉进目标区 | 通过 | `lower` 检出夹垫与工件的必需接触丢失。 |
| 工件生成在桌面内部 6 mm | 通过 | `initial` 检出 `block/table` 超过本夹具的 0.5 mm 支撑穿透上限。 |
| 1 mm 薄墙，球尖一个物理步移动 24 mm | 通过，采样点无接触 | `traverse` 检出移动几何体跨越有限墙面。 |
| 同一薄墙，在运行前提供实际直线插值 | 通过 | 路径预检在 `traverse` 检出 `tip/wall`，在步进前停止。 |

夹持、下落和落台均由物理积分产生。正例测得工件与台面最大穿透约 0.247 mm、夹垫与工件约 0.683 mm，本测试为这两对分别采用 0.5 mm、1 mm。其他材料、几何尺度、步长或夹持力应用各自的阈值。

## 用相同题目比较 Codex 与其他 agent

为每个 agent 提供相同版本的两个 skill、相同可写空目录、解释器和依赖、相同任务描述及已经确认的用户答复。保存模型标识、工具权限、版本、提示词、每次运行日志和最终报告。把已知故障的验证和判分留在独立目录，避免把预期诊断或补丁直接写进提示词。

1. **模型题** 用内置带驱动双轴正例生成 MJCF 并交给任务 skill，再用同一七轴输入检查装配例外、干涉姿态和实际验收范围。验收方可另引入非配合零件干涉，检查报告定位。
2. **抓放题** 提供同一机器人、桌面、夹具、动态工件、SI 参数、任务轮次和完成条件。要求实现夹取、搬运、放置。验收方分别引入一次前臂撞桌和一次提前失去夹持，核对首个违规阶段及零件对。
3. **薄板题** 提供相同薄板尺寸、目标轨迹和运动速度，要求给出可运行方案。验收方加入中段过墙的路径和步间跨墙反例，同时保留可绕行的正例。

每题记录首次执行是否跑通、故障漏检数/已知故障数、合法工况误报数/合法工况数、agent 修正次数和最终任务目标是否达成。记录需要人工补充的信息及原因。先逐题比较再汇总；缺少某个 agent 的实际运行记录时，其结果留空。上表是脚本回归结果，跨 agent 指标须用独立运行记录填写。

## 已做的独立试用

2026-11-23，单独的 Codex 会话只接收两个 skill、合成任务和已安装的离线解释器。任务为使用内置带驱动双轴臂，保留原位置伺服，J1 一秒内到 +0.12 rad，下一秒回零，J2 保持初始位置，全程容差 0.025 rad。初次使用 MuJoCo 4.0.1 验证模型发现旧质量矩阵 API 兼容错误。修复后重跑原命令通过。任务合同、路径预检及正式任务首次通过，J1 两个终点误差分别为 0.00718 和 0.00713 rad，J2 最大偏差 0.00971 rad，两段轨迹及 2001 条状态记录完整。控制器为补偿重力挠度给 J2 参考量设置了 −0.035 rad 静态偏置。测试使用 Windows x64、CPython 3.12、MuJoCo 4.0.1。

DeepSeek 同题结果待独立测量。对照时同时保留首次错误、修正记录和最终结果。
