# Dexbot_ana.zip 源码分析与采用范围

用户提供压缩包约247MB，含1,190个文件，包括cuRobo源码、URDF、STL和历史结果。本次只读取参考算法与模型数据，没有安装或运行压缩包中的代码。文件指纹见[source-provenance.json](source-provenance.json)。

## 原工程职责

- `robot_arm_moverange.py`：按URDF限位做单臂随机/网格采样，cuRobo批量FK得到末端点云，支持双臂分别输出。
- `moverangeSolver.py`：围绕J1原点采样球壳及内部层；生成工具+Z朝球心的参考姿态和Euler扰动，IK成功查询按目标点计数；输出三维热力图、三投影/切片、NPZ及报告。
- `issac_ikSolver.py`：封装cuRobo FK/IK及可选碰撞、环境障碍接口。
- `dual_arm_curobo_new.yml`与URDF：双臂14个主动关节配置。YAML中collision_spheres为空；分析主程序默认关闭自碰撞，不能据求解器有碰撞接口就声称历史工作空间通过碰撞过滤。

历史报告为右臂、球半径0.7m、118个位置、16姿态/点、1,888个IK查询。它是旧运行快照，不用作新Skill的数值结果。历史“≥75%完全可达”标签不能解释为全部姿态可达；本Skill只报告实际采样成功率。

## 当前实现对应

| 参考能力 | 当前实现 |
|---|---|
| 随机/网格 FK 点云 | 独立Node CPU内核，固定种子与预算，保留每点q |
| 球内目标与姿态查询 | 分层球采样、base/radial姿态、位置或6D IK |
| GPU批量多初值IK | 替换为CPU多初值阻尼雅可比；不保证与cuRobo相同成功率 |
| PNG/NPZ结果 | 结构化JSON、CSV、Markdown、SVG及网页交互点云 |
| URDF模型 | 左右臂几何参数快照，另提供标准库URDF路径转换器 |
| 双臂协同与碰撞接口 | 当前未实现，左右臂独立分析不能替代协同校核 |

球采样改用等面积纬度带并去重球心/极点，点数与原工程不同；随机数算法和局部IK也不同。相同输入参数不应期待逐点匹配原GPU结果。

## 模型差异

URDF中右肩J1原点为 `[0,-0.17,0]`，左肩为 `[0,0.17,0]`；J1/J2/J3共点，沿链主要长度为300/213/47/40mm，零位从肩到末端600mm。
现有网页WORKSHEET模型为七段35/50/250/50/163/47/40mm，J1到末端635mm，属于不同几何模型。新Skill提供分开的参考请求，不能把一个模型的q与点云直接套在另一个模型上。

左右臂URDF参数在读取XML时提取，没有运行用户源码。20组零位/随机姿态采用独立Python 4×4齐次矩阵计算形成回归夹具；Node内核逐项对照末端位置与旋转矩阵。
