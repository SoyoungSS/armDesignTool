# 安装姿态与重力配置

日期：2026-10-28。Skill 内核版本1.1.0，网页计算内核版本1.4.0。

## 目的

支持机械臂正装、倒装、侧装和任意倾斜安装。J1轴向与基座安装朝向独立配置；不能从J1的单根轴推断基座的完整姿态。

## 坐标与计算

- W：世界坐标系，通常Z向上。
- B：机械臂物理模型的基座坐标系。
- Ji：各关节局部坐标系，描述关节轴、所属刚体质心等。

安装RPY为弧度，约定 `R_WB=Rz(yaw)Ry(pitch)Rx(roll)`，将B中向量转换到W。
重力计算使用 `g_B=R_WBᵀg_W`；物理模型留在B中，静力学公式保持不变。
网页旧重力内核和动力学中的重力项也消费该转换结果；几何、惯量和IK仍在B中。

三维渲染通过转换观察基向量呈现整体安装旋转，机械臂、安装板与点云共同旋转；世界网格与W坐标轴保持在世界中。旋转环和鼠标射线仍在B中求交。显示增加W/B坐标轴及重力箭头。

模型内的根安装（`simple.base` 或首关节 `origin`）相对B表达，与B相对W的安装角不同。两层变换允许同时存在，但同一个安装角不能重复填写。

## Skill 请求

旧输入继续支持：

```json
"gravity_m_s2": [0, 0, -9.81]
```

新输入示例（绕世界Y方向对应的安装Pitch 90°）：

```json
"installation": {
  "gravity_world_m_s2": [0, 0, -9.81],
  "base_orientation_in_world": {
    "rpy_rad": [0, 1.5707963267948966, 0]
  }
}
```

两种输入必须二选一，不允许同时存在或全部缺失；拒绝未知字段、维度错误和非有限数值。零重力可以显式输入。
向后兼容Schema 1.0；新版本增加可选输入方式，内核版本提升。旧输入物理结果不变，完整结果中的内核版本与标准化哈希可能变化。

示例：[side-mounted-two-link.json](../arm-statics-parametric/assets/examples/side-mounted-two-link.json)。

## 网页使用

1. 按根README启动网站；进入“规格与模型”或“静力学分析”。
2. 在“基座安装与重力”选择正装、倒装、侧装，或编辑安装角与世界重力。
3. 预设选择会自动重算网页概念结果；自定义数值编辑后点击顶部“运行全流程”。
4. 在静力学页载入或上传与当前几何一致的Skill输入。
5. 点击“应用网页安装设置到输入”：保留机械臂参数，将重力输入替换为当前安装配置。JSONC由Skill原解析器读取，写回为格式化严格JSON，注释不保留。
6. 点击“运行静力学Skill”，再选择关节临界姿态。

网页在接收结果时检查基座重力；若结果带有安装矩阵，也检查其朝向是否一致。不一致时拒绝显示并提示重新应用安装设置。
仍需核对几何、轴向、质量归属与限位；安装检查不构成完整物理模型等价证明。

安装编辑和网页重算均使旧结果失效。运行期间改变模型或输入文本，旧响应会被丢弃。
切换机械臂模板保留已显式配置的安装设置；恢复示例重置安装。

## 输出与追溯

`normalized_input.gravity_m_s2`：本次实际使用的基座重力。

使用新输入时还包括：

```text
normalized_input.installation.gravity_world_m_s2
normalized_input.installation.base_orientation_in_world.rpy_rad
normalized_input.installation.rotation_base_to_world
```

输入快照、输入哈希和标准化哈希保留安装信息；CLI Markdown报告写出安装与重力。
`standard_request.json`保留可复算安装输入，网页概念JSON与HTML报告也保留安装条件。
输出几何仍在B中，显示到世界时只转换一次。
