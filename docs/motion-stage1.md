# 轨迹、奇异性与动态载荷使用说明

日期：2026-11-10；独立 Skill：arm-kinematics-dynamics，动态载荷版本 0.2.0。

## 使用网页

重启 srs-lab-source 中的网站服务并强制刷新，打开 `http://localhost:8787/#motion`，或左侧“轨迹与奇异性”。

1. 选择选型表七轴单臂或 Franka FR3，点击“载入轨迹示例”。
2. 可编辑每段运动时长、采样间隔、位置/完整位姿任务；起止关节位置、保持段和逐关节限制可在 JSON 中编辑。
3. 点击“运行轨迹分析”。查看 q/dq/ddq 曲线，拖动时间游标或播放几何姿态；点击事件跳到对应时间。
4. 点击“载入选型表奇异工况”再运行，可观察接近零位的秩下降。本工况运动约束通过，但存在奇异区间；二者是不同判据。
5. 导出完整结果 JSON 或关节时序 CSV。顶部旧“导出结果”仍属于概念内核，不包含本页独立结果。

本页采用独立请求，不因主网页当前模型是选型表就将 FR3 改为选型表，也不依赖主网页模型的质量/惯量。更改本页输入使本页结果失效，运行中修改输入会丢弃过期响应。

## 随机关节轨迹

1. 载入轨迹示例，或在编辑区粘贴含逐关节运动限制的请求。生成沿用当前模型和起点。
2. 在“关节空间随机生成”中设置种子、轨迹条数、每条运动段数、最大单段位移、速度与停留范围，再点击“生成随机轨迹”。
3. 用下拉框切换轨迹。所选轨迹载入 JSON 编辑区，点击“运行轨迹分析”查看机械臂预览、关节位置、速度、加速度和奇异事件。可下载生成批次 JSON，批次中每条轨迹的 `request` 都可单独分析。

最大单段位移按各关节行程的百分比计算。速度百分比是段时间系数的倒数。比如抽到 50% 时，该段时长为速度、加速度和可选跃度限制共同决定的最短时长的两倍，至少为一个采样间隔。轨迹经过每个关键点时速度和加速度均归零。保持模型、起点、采样间隔和随机设置相同，可复现同一批轨迹。

## 独立调用

从工程根目录运行，无需启动网页：

```shell
node arm-kinematics-dynamics/scripts/run.mjs --input arm-kinematics-dynamics/assets/examples/franka-fr3-motion.json --output outputs/motion-result.json --report-dir outputs/motion-report
```

导出 result JSON、trajectory.csv、report.md 和原始 request.json。共享依赖随 bundle 分发；打包器已支持新 Skill。

请求契约为 shared/contracts/motion-request.schema.json，细则见 arm-kinematics-dynamics/references/input-contract.md。程序入口 analyze(input) 位于 scripts/lib/analyze.mjs。Node.js >=20，无第三方运行依赖。

## 已实现

- 五次多项式关节停靠轨迹，保持/等待/返回；解析 q/dq/ddq。
- strict 固定时长诊断；stretch 根据速度/加速度及可选跃度限制延长时长，保留原时长。
- 段内位置单调性与速度/加速度/跃度解析极值检查，非仅采样判据。
- 外部轨迹 ID 映射；缺导数保留 null，显式选择才做非均匀时间三点估计。
- 复用公共 FK/雅可比；TCP 固定偏移、基座/世界位姿、基座系速度和加速度。
- Jacobi SVD、任务维数、尺度化奇异值、数值秩、条件数、风险区间与近限位关节。
- 数值秩下降与结构性欠驱动区分；无限条件数用 null + infinite 标记，不向 JSON 写 Infinity。
- 输入/模型哈希、参数假设、CLI 来源；错误不回退示例结果，失败不覆盖成功主结果。
- 独立 API/CLI、网页真实子进程桥接、最多两个并发任务、取消与临时目录清理。

## 明确的边界

- 当前只生成关节空间轨迹，关键点全部停靠；不生成连续通过的笛卡尔路径，不复制工作空间 IK，也未新增自动避奇异功能。
- 现有 IK 仍由工作空间 Skill 使用；后续需要连续笛卡尔路径时，再提取/复用求解入口，而不是复制算法。
- 动态载荷在“轨迹与奇异性”页启用。网页旧“动力学分析”页仍使用概念内核。模组额定能力、热和寿命待后续接入。
- 奇异性及近限位区间为采样观察，不是连续区间证明；阈值依赖任务与特征长度，不是通用安全边界。
- TCP 加速度使用方向中心差分 Jdot；导入数据若估计导数，噪声会放大且未自动滤波。
- 外部样本通过仅为 samples_passed，trajectory_feasible=null；缺信息是 incomplete。生成轨迹的 verified 只证明已声明运动约束，不代表真实机器人任务通过。
- 演示运动限制 1 rad/s、2 rad/s² 是显式假设，不是 FR3 厂商额定参数。
- 当前外载荷支持作用于物理 tip 的恒定世界系力/力矩；负载装卸及分阶段外力事件待后续扩展。

## 实际验证

本轮共132项 Node测试通过：新轨迹 Skill 12项、公共契约/分发10项、网站24项、静力学64项、工作空间22项。

覆盖解析轨迹边界和极值、粗采样下超限、自动放慢、保持段、非均匀导数、TCP向心加速度、安装变换、已知奇异值、两杆秩下降、长度尺度一致性、两个公开模型、JSON原生结果一致性、CLI失败保留旧输出和仓库外分发。

真实浏览器验收：选型表零位工况5秒、257点，53个奇异样本和78个近奇异样本；点击事件定位到2秒姿态，显示秩5/6；播放期间时间游标递进。FR3常规轨迹另行在页面执行和预览。完整体素工作空间与Isaac Sim不属于本轮验收。


## 第三阶段动态载荷

重启网页服务并刷新“轨迹与奇异性”页，点击“载入选型表动力学演示（球体惯量估算）”，再点击“运行轨迹分析”。也可先生成随机轨迹，选择一条后分析。选择状态量“力矩 / 推力”查看时序曲线，在“动态载荷与关节接口”表中查看峰值、RMS、机械功率、轴向力、径向力和弯矩；点击峰值时刻可定位关节及机械臂姿态。动态载荷 CSV 使用独立按钮导出。

演示部件的 COM 惯量按半径 0.04 m 均匀实心球估算，3 kg 负载采用半径 0.05 m。这些参数仅用于演示计算流程，应以 CAD、实测或有依据的几何估算替换。真实输入在 JSON 中补齐质量、COM 和惯性张量，勾选“计算动态载荷”。FR3 仍需补充惯性数据。

```shell
node arm-kinematics-dynamics/scripts/run.mjs --input arm-kinematics-dynamics/assets/examples/worksheet-dynamics.json --output outputs/dynamics-result.json --report-dir outputs/dynamics-report
```

输出含 dynamic-loads.csv、trajectory.csv、report.md 及 request.json。CLI 与网页复用同一内核。动态力矩为关节输出端刚体需求，当前尚需在模组选型阶段加入摩擦、传动效率、电机转子惯量与额定能力。
