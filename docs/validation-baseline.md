## 复现与限制

网站：在 srs-lab-source 设置 STATICS_SKILL_DIR 后 npm start；更新服务端后重启，浏览器 Ctrl+Shift+R。

CLI 与打包复现见 shared/README.md。新增契约版本为 1.0；既有两个求解内核算法版本保持不变，因为本轮不改变其数值算法，代码快照由提交与模型哈希区分。

本轮未开始 P2 轨迹/动力学开发，未接入或运行 Isaac Sim，未对实际模组作选型通过判定。后续惯量、温升和真实 CAD 质量校正仍需独立验证。
