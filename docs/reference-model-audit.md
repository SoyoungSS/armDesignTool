# P0 参考模型与数据来源审计

日期：2026-11-05。参考资料只读，当前标准参数模型不自动用 URDF 数据覆盖。

## 模型区分

- worksheet_reference：由现有静力学 worksheet-minimal.json 的标准化转换生成，质量合计 3.612 kg，保留原轴向、局部 COM 和几何。该模型来源是选型表概念分配，惯量未提供，因此能力为 geometry + mass_properties。
- cad_urdf_reference：ArmReference/dual_arm 中的双臂 URDF。右臂已登记质量 2.61908817 kg、左臂 2.62234333 kg，不含共同基座。URDF 文件 link_8 无 inertial，不能因此推断实际末端无质量。
- 两套模型轴心偏置、质量覆盖和来源不同，不应混用“同模型验证”结论。本阶段只记录差异，不擅自确定哪份更准确。

## 已确认的契约

轴是安装变换之后的局部方向；joint origin 相对前一输出刚体；COM 关于当前输出刚体系。世界安装与局部几何分开。根示例采用 SI 单位，关节名称用于既有求解器，稳定 ID 用于跨模块映射。

单杆与两杆使用解析理想细杆质量和 COM 惯量，注明概念假设；七轴未根据等效 COM 虚构惯量。静力学 payload 是显式附加点质量，工具/附件不得再次作为同一 payload 重复计入。

## 仍待设计者确认

1. URDF 与表格的模组固定端/运动端、壳体、线缆、附件覆盖及 CAD 装配版本。
2. worksheet 等效 COM 与后期真实刚体惯量的替换关系。
3. 参考表 EC-A4315 额定扭矩 20 N·m 与厂家手册 25 N·m 的型号版本及适用条件；当前 P0/P1 不合并能力值，也不据此做选型通过判定。
4. 重复定位精度、热保持和寿命仍需要其独立证据，本阶段几何/静力结果不予证明。
