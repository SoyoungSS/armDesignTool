# 共点关节与模组布置 axis-module-layout-v1

本规则生成概念机械结构，固定算法位于 scripts/arm_sim/joint_layout.py。无需新依赖。所有格式复用同一套布置结果；不修改 model.joints、安装、tip、poses、关节限位或驱动参数。

## 运动学与实体分开

关节 origin 可以位于两条旋转轴的交点；电机/减速器包络中心可以沿对应轴线移开。只改变 Mesh 顶点和部件局部变换，不把实体偏移写入 URDF/MJCF/USD 关节 origin。给定质量、COM、惯量仍按原刚体归属使用，不能因视觉移位而自行迁移质量。概念质量代理仍是单独记录的原始实体近似，不从新轴套/重叠件体积重复计重；不代表内部传动已经设计完成。

## 识别与适用范围

- 在几何零位统一到同一坐标系比较轴和安装点，不能直接比较不同局部系的 axis。
- 寻找最近上游非共点 origin；其到当前点的方向与轴夹角（忽略正负号）不超过15°，判为轴向自转候选，否则为横向摆动候选。末端另检查工具 Z 轴，避免把末端法兰自转误判成摆动。无有效参考方向则 undetermined；显式 role 优先。
- 当前自动布置针对**两个相邻 revolute，后者 origin 平移长度 ≤1e-8m**。上游自转＋下游摆动为 twist_bend；两轴平行度 abs(dot)≥1−1e-10 且上游自转为 coaxial_stack。不是根据关节编号、品牌或输入名称选择。
- 三个以上共点旋转轴、两个摆动轴或无上游轴向空间，不猜内部万向传动，报告 unresolved/needs_review。近似共点、非共点的相交轴及隔 fixed 的组合保留原外壳规则，不自动移动。移动轴保留导轨/滑块，不套用旋转轴套规则。

## 固定布置算法

1. 采用已给定或原尺寸策略生成的模组直径/轴向长度。摆动模组沿自己的正轴侧置，后端面避开输出连杆部件在该轴上的投影包络，并留 clearance。同轴第二模组默认仍在交点。
2. 自转模组向上游退让；方向由入臂向量在自转轴上的投影符号确定。轴反向时物理退让方向仍正确，不能硬编码为局部 -Z。
3. 按圆柱包络在退让轴上的投影计算最小退让。投影半长为 `h=(L/2)*abs(a·b)+R*sqrt(1-(a·b)^2)`。结合摆动模组侧置中心，要求两个包络沿退让轴至少分离 clearance。正交且侧置不改变该投影时，简化为 `retreat ≥ L_twist/2 + R_bend + clearance`。
4. 自转模组的后端必须处于上游有效轴向长度的85%以内，给前一安装点保留空间。空间不足或显式退让小于最小值，失败并列出原因，不能改关节位置补空间。
5. 固定壳使用有真实内孔的封闭环形 Mesh，归 parent；轴/输出套筒、环形分界和输出盘归 child。自转输出轴止于横向轴包络之前，避免两根实心轴穿插；同轴组合保留连接法兰，并按臂段方向选择输出侧，不硬编码轴正方向。摆动模组固定壳归它的 parent，即前一个自转输出连杆。加入同一固定端的侧支承，避免模组悬空；上游连续外壳截短到固定模组后端，露出自转环缝。这些支承是概念近似，不证明完整刚度/轴承设计。
6. 模组、输出件的局部坐标和 owning_link/assembly_role 写入 normalized_model.geometry。固定壳随上游关节运动，但不会错误跟随自己的输出关节转动。

## 可选输入

零新增字段也自动处理符合条件的组合。覆盖项：

```json
{"dimensions":{
  "appearance":{"assembly_clearance_mm":2},
  "joints":{"J1":{"role":"axial_twist","module_retreat_mm":130},
            "J2":{"role":"transverse_bend"}}
}}
```

- role 为 auto（默认）、axial_twist、transverse_bend；非 revolute 不允许显式旋转角色。
- module_retreat_m 或 module_retreat_mm：正数，只允许支持组合中的第一个关节；数值为退让距离而非新关节偏移。未填写时按包络推导，显式值保留并校验。
- assembly_clearance_m 或 assembly_clearance_mm：正数，默认0.002m。
- 同一数值不能同时使用 m/mm。原有 diameter/axial_width 和 max_envelope 继续有效，最终外廓包含分配到上游的新部件。

## 验证与交付

report/joint_layout.json 记录角色判断依据、所选组合、退让/侧置量、固定端/输出端连杆、圆柱包络和未解决项。axis_base_zero 表示零位下在基座坐标系表达的轴，axis_frame 标明基座名称；它不包含世界安装旋转。人可读报告提供组合摘要。

validation.json/module_packing 独立于仿真 collision_exclusions：在零位、初始、验收及固定采样姿态，对已布置模组圆柱做投影分离检查，组合内要求设计 clearance，组合间要求无包络交叠。投影检查不能分离的情况记 potential_envelope_conflict，目标失败等待复核；它不是精确相交算法。未支持组合使 assembly_validation=needs_review、目标 status=pending，即使短步进成功也不升级为整体验证通过。

检查范围是本规则生成的模组包络，轴/轴承配合和其他壳体干涉仍在原几何筛查报告中；不能把配合碰撞排除当作模组装得下的证据。多个有限姿态通过不构成全行程/制造装配证明。

回归核对：原始 FK 和物理参数不变、环形 Mesh 闭合且有内孔、固定/运动端实际跟随关系、mm/安装旋转/轴反向、显式尺寸不足失败、同轴组合、不可自动布置的多轴组合不误报通过。
